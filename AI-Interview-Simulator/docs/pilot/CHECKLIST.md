# Pilot checklist

Έκδοση 0.1 — 2026-10-23. Κενά κουτιά σημαίνουν **δεν έχει επιβεβαιωθεί**.
Δεν είναι λίστα ολοκληρωμένων δοκιμών αυτού του κύκλου. Υπεύθυνος/η, ημερομηνία,
έκδοση εφαρμογής/υλικού και αποτέλεσμα καταγράφονται σε κάθε εκτέλεση.

## 0. Πριν από πρόσκληση οποιουδήποτε πραγματικού συμμετέχοντα

- [ ] Επιβεβαιώθηκε η απαιτούμενη θεσμική/δεοντολογική διαδικασία, χωρίς αυθαίρετο ισχυρισμό έγκρισης.
- [ ] Οριστικοποιήθηκε το ενημερωτικό με υπεύθυνο, επαφές, διατήρηση, πρόσβαση και αιτήματα δεδομένων.
- [ ] Ελέγχθηκε η φόρμα του επιβλέποντα έναντι του προσχεδίου.
- [ ] Επιβεβαιώθηκαν εθελοντική συμμετοχή και μη σύνδεση με βαθμολογία/αξιολόγηση.
- [ ] Επιβεβαιώθηκαν ηλικία ενηλίκου, ακαδημαϊκή επιλεξιμότητα και έννοια πρόσφατου αποφοίτου.
- [ ] Έχουν συμφωνηθεί τα ελάχιστα δημογραφικά, χωρίς περιττά προσωπικά στοιχεία.
- [ ] Κλειδώθηκε η ακριβής έκδοση MASI και η τεκμηρίωση δικαιωμάτων/μετάφρασης/προσαρμογής.
- [ ] Κλειδώθηκαν ακριβές ελληνικό SUS και ελληνικό λεκτικό/anchors Raw TLX.
- [ ] Κλειδώθηκε το κοινό σενάριο και επιβεβαιώθηκε ότι οι επτά ερωτήσεις είναι αμετάβλητες.
- [ ] Επιβεβαιώθηκαν σειρά/οδηγίες εργαλείων χωρίς προσθήκη outcomes ή pre-test.
- [ ] Ενσωματώθηκαν και δοκιμάστηκαν consent gate, surveys και ανεξάρτητη ολοκλήρωση συμμετοχής.
- [ ] Υπάρχει σαφής δυνατότητα διακοπής και διαδικασία για ήδη αποθηκευμένα δεδομένα.

## 1. Hosting / πάροχος — με άδεια πριν εκτέλεση

- [ ] Participant ownership και πρόσβαση ελέγχονται στον server, ακόμη και με αλλαγμένα ids.
- [ ] Export/admin πρόσβαση περιορισμένη· δεν εκτίθενται backup ή αρχεία βάσης.
- [ ] Rate limits και όρια εισόδου προστατεύουν αποθήκευση/χρεώσιμες κλήσεις χωρίς σιωπηρή περικοπή κειμένου.
- [ ] API/CORS/reverse proxy/HTTPS/SignalR ελέγχθηκαν στο συγκεκριμένο staging.
- [ ] Runtime υποστηριζόμενο σε όλη την περίοδο έρευνας· λύθηκε το θέμα .NET 8 μετά τις 10/11/2026.
- [ ] Μόνιμο SQLite storage με κατάλληλο locking, μία API instance, backup και επιτυχές restore.
- [ ] Ξεχωριστές pilot/ιστορικές/κύριες βάσεις· δεν αλλάχθηκε ο αλγόριθμος κατανομής.
- [ ] Secrets μόνο σε ασφαλή server-side ρύθμιση, όχι αρχεία/logs/frontend.
- [ ] Επαληθεύτηκαν active paid Gemini project, διαθέσιμο μοντέλο, quotas και ειδοποιήσεις κόστους.
- [ ] Έγινε εγκεκριμένο live smoke test με συνθετικά κείμενα· καταγράφηκαν ακριβές μοντέλο/ημερομηνία.
- [ ] Καμία Β αποτυχία δεν μετατράπηκε σε Α feedback.
- [ ] Δεν δημοσιεύτηκε το test host ή τα /test/* endpoints.

## 2. Τελική τεχνική πρόβα — συνθετικά δεδομένα

- [ ] Χωρίς αποδοχή συναίνεσης, UI και απευθείας API δεν δημιουργούν συμμετοχή.
- [ ] Κείμενο και έκδοση αποδοχής αποθηκεύονται πριν τη συνεδρία, χωρίς προεπιλεγμένο checkbox.
- [ ] Άκυρη ηλικία, κενά/εκτός κλίμακας δημογραφικά και μη επιλέξιμος συμμετέχων αντιμετωπίζονται σωστά.
- [ ] Και στα δύο conditions εμφανίζονται ακριβώς οι ίδιες ερωτήσεις και το κοινό σενάριο.
- [ ] Α χωρίς αναθεώρηση: επτά ερωτήσεις, πρώτο feedback ανά απάντηση, συνέχεια και τέλος.
- [ ] Α με αναθεώρηση: δύο χωριστά feedback και μόνο «Συνέχεια» μετά το δεύτερο.
- [ ] Β χωρίς/με αναθεώρηση: ίδια ροή· δεύτερη παραγωγή μόνο με τη νέα απάντηση.
- [ ] Άσχετο/πολύ σύντομο/παραφρασμένο ελληνικό κείμενο δεν οδηγεί σε παραπλανητική βεβαιότητα.
- [ ] Επανάληψη αποθήκευσης και απώλεια απόκρισης μετά commit δεν προσθέτουν απαντήσεις/χρόνους.
- [ ] Concurrent αιτήματα δεν δημιουργούν δεύτερη αναθεώρηση ή αντικατάσταση feedback.
- [ ] Timeout, 429/άλλη αποτυχία και μη έγκυρο feedback επιτρέπουν ασφαλές feedback-only retry.
- [ ] Refresh στο πρώτο feedback, editor και δεύτερο feedback επαναφέρει server state χωρίς νέα συμμετοχή.
- [ ] Δεν παρουσιάζονται χαμένοι browser χρόνοι ως πλήρεις· δεν υπόσχεται αποθήκευση μη υποβληθέντος draft.
- [ ] Stage 7 κλείνει μόνο με την επιτρεπόμενη συνέχεια, όχι με υποβολή αναθεώρησης.
- [ ] Δοκιμάστηκαν mobile viewport, πληκτρολόγιο, εστίαση και μεγάλα κείμενα στο πραγματικό staging.

## 3. Ερωτηματολόγια

- [ ] Μετά το τέλος της συνέντευξης εμφανίζονται τα εργαλεία, όχι μόνο μήνυμα ολοκλήρωσης.
- [ ] Οδηγίες αναφέρονται στη σωστή εμπειρία και χρονικό πλαίσιο.
- [ ] Items, σειρά, anchors και ranges αντιστοιχούν στην εγκεκριμένη έκδοση.
- [ ] Το SUS scoring διατηρεί τα αντίστροφα items και επαληθεύεται με γνωστά διανύσματα.
- [ ] Raw TLX: έξι ρητές αποκρίσεις, χωρίς ακούσια default τιμή ή pairwise weighting.
- [ ] Η κατεύθυνση Performance ελέγχθηκε χωρίς διπλή αντιστροφή.
- [ ] MASI key/υποκλίμακες/αντιστροφές ελέγχθηκαν έναντι της ακριβούς τελικής έκδοσης.
- [ ] Missing responses δεν γίνονται αυτόματα μηδέν· ο χειρισμός ακολουθεί το συμφωνημένο σχέδιο.
- [ ] Survey retry/refresh δεν διπλασιάζει αποκρίσεις ή ξαναγράφει ολοκληρωμένα δεδομένα.
- [ ] Η ολοκλήρωση συμμετοχής διακρίνεται από το FinishedAt συνέντευξης και από αποχώρηση.

## 4. Μικρό ερευνητικό pilot — μόνο μετά τα παραπάνω

Πρακτική πρόταση: λίγοι επιλέξιμοι εθελοντές, π.χ. 4–6 συνολικά, με κάλυψη και
των δύο συνθηκών μέσω της υπάρχουσας κατανομής. Δεν είναι επαρκές δείγμα για
ψυχομετρική επικύρωση, power analysis ή συμπεράσματα Α/Β.

- [ ] Καταγράφηκε χρόνος πλήρους διαδικασίας για ορθή μελλοντική ενημέρωση διάρκειας.
- [ ] Ελέγχθηκε κατανόηση σεναρίου από διαφορετικά γνωστικά αντικείμενα.
- [ ] Οι συμμετέχοντες κατανοούν μία αναθεώρηση, δεύτερο feedback και δυνατότητα αποχώρησης.
- [ ] Ελέγχθηκε κατανόηση της ελληνικής διατύπωσης των εγκεκριμένων items χωρίς καθοδήγηση απαντήσεων.
- [ ] Καταγράφηκαν τεχνικά συμβάντα/διακοπές χωρίς εισαγωγή νέου primary outcome.
- [ ] Έγινε χειροκίνητος έλεγχος καταλληλότητας feedback· τα unit tests δεν θεωρήθηκαν τεκμήριο NLP ακρίβειας.
- [ ] Δεν παρουσιάστηκε η επιλογή αναθεώρησης ως απόδειξη βελτίωσης δεξιοτήτων.

## 5. Δεδομένα και απόφαση συνέχισης

- [ ] Export: condition, session/stage ids, δύο απαντήσεις, δύο feedback, εκδόσεις, χρόνοι, δημογραφικά.
- [ ] Export συναίνεσης/surveys: raw αποκρίσεις, έκδοση εργαλείου, completion και όπου προβλέπονται derived scores.
- [ ] Join interview/surveys ανά session χωρίς πολλαπλασιασμό συμμετεχόντων επί επτά stages.
- [ ] Χρόνοι συγγραφής, παραγωγής, αναμονής και συνολικού stage διατηρούν διαφορετικούς ορισμούς.
- [ ] Browser acknowledgements δεν ερμηνεύονται ως απόδειξη ανάγνωσης/προσοχής.
- [ ] Κάθε export ελέγχθηκε έναντι βάσης για πλήθος, ids, κείμενα και null ιστορικά πεδία.
- [ ] Η πραγματική ιστορική βάση δεν χρησιμοποιήθηκε ως scratch test database.
- [ ] Δεν διαγράφηκαν αποχωρήσεις/ελλιπή δεδομένα ή άλλαξε το σχέδιο ανάλυσης χωρίς απόφαση.
- [ ] Τεκμηριώθηκαν bugs, διορθώσεις και τελικές εκδόσεις εφαρμογής/prompt/κανόνων/items/σεναρίου.
- [ ] Ο επιβλέπων αξιολόγησε τα ευρήματα pilot πριν πρόσκληση κύριας έρευνας.
