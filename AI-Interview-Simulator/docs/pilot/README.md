## Δημογραφικά — πρόταση, όχι αλλαγή φόρμας

| Στοιχείο | Πρόταση |
|---|---|
| Ψευδώνυμο, υποχρεωτικό σήμερα | Προτιμότερος αυτόματος κωδικός και γενική ετικέτα chat. Αν διατηρηθεί, οδηγία να μην είναι πραγματικό όνομα. Δεν χρειάζεται για τα outcomes |
| Ηλικία, ακέραιος 18–99 στο UI | Διατήρηση του υπάρχοντος πρωτοκόλλου χωρίς ημερομηνία γέννησης. Ο server πλέον επιβάλλει το ίδιο εύρος. Εναλλακτικά εύρη μόνο μετά συμφωνία |
| Φύλο, Male/Female/Other σήμερα | Προαιρετικό αν δεν υπάρχει ειδική υπόθεση· χωριστά «Άλλη ταυτότητα» και «Δεν επιθυμώ να απαντήσω». Σήμερα η επιλογή Other συνδυάζει και τα δύο |
| Εξοικείωση AI, Low/Medium/High σήμερα | Διατήρηση μέχρι συμφωνία· διευκρίνιση ότι αφορά παραγωγική AI. Δεν αντικαθίσταται σιωπηρά από συχνότητα χρήσης |
| Φοιτητής/πρόσφατος απόφοιτος | Σύντομη επιβεβαίωση επιλεξιμότητας· να οριστεί το «πρόσφατος» |
| Προηγούμενες συνεντεύξεις | Προαιρετική προτεινόμενη προσθήκη: 0 / 1–2 / 3–5 / 6+ / Δεν απαντώ, μόνο αν αξιοποιηθεί στην περιγραφή/ερμηνεία |
| Εργασιακή εμπειρία, σχολή | Όχι αναγκαίες προσθήκες στο ελάχιστο pilot. Αν υπάρχει συγκεκριμένος αναλυτικός σκοπός, ευρείες κατηγορίες αντί μικρών αναγνωρίσιμων ομάδων |

Δεν χρειάζονται όνομα, ΑΜ, email, τηλέφωνο, διεύθυνση ή βιογραφικό.
Κωδικοποίηση δεν σημαίνει εγγυημένη ανωνυμία: ελεύθερες ιστορίες και συνδυασμοί
δημογραφικών μπορεί να αποκαλύπτουν ταυτότητα. Τα δημογραφικά δεν τροφοδοτούν feedback.

## Μικρή τεχνική διόρθωση αυτού του κύκλου

Η CreateUser απορρίπτει ηλικίες εκτός του ήδη υπάρχοντος εύρους UI και κενό
ψευδώνυμο, και αφαιρεί μόνο περιβάλλοντα κενά από το ψευδώνυμο. Δεν άλλαξαν
κλίμακες ή ιστορικές εγγραφές. Προστέθηκαν regression checks σε προσωρινή βάση.

## Επόμενη ενσωμάτωση, μετά την οριστικοποίηση

1. Ενημέρωση/επιλεξιμότητα/συναίνεση → ελάχιστα δημογραφικά → κοινό σενάριο →
   υπάρχουσα συνέντευξη → ερωτηματολόγια → ολοκλήρωση συμμετοχής.
2. Καταγραφή ConsentVersion, αποδοχής, έκδοσης σεναρίου και study phase,
   με nullable ιστορικά πεδία. Ο server απορρίπτει μη συναινετική έναρξη.
3. Survey completion χωριστά από το υπάρχον InterviewSession.FinishedAt.
4. Έκδοση item bank, raw αποκρίσεις, validation, idempotent αποθήκευση και exports.
5. Ξεχωριστή βάση pilot από ιστορικά/κύρια δεδομένα. Δεν αλλάζει ο αλγόριθμος
   κατανομής ούτε διαγράφεται η υπάρχουσα βάση. Τα pilot δεδομένα δεν αναμειγνύονται
   αυτόματα στην κύρια ανάλυση.

## Αποφάσεις που απαιτούν επιβεβαίωση

- Τελικό ερευνητικό υλικό: MASI και δικαιώματα/προσαρμογή, ακριβές ελληνικό SUS,
  ελληνική απόδοση/anchors Raw TLX, ελάχιστα δημογραφικά και προτεινόμενο σενάριο.
- Θεσμικά στοιχεία: υπεύθυνος, επαφές, πρόσβαση, διατήρηση, αποχώρηση/διαγραφή
  και τυχόν απαιτούμενη δεοντολογική διαδικασία.
- Άδεια για πραγματικό μικρό Gemini smoke test και συγκεκριμένο Azure staging
  deployment/κόστος αφού κλείσουν τα security gates.

Συντομότερη σειρά: κλείδωμα υλικού/στοιχείων → συναίνεση και surveys →
security/runtime → staging κατόπιν άδειας → synthetic live Gemini test κατόπιν
άδειας → πλήρης πρόβα και μικρό Α/Β pilot → έλεγχος δεδομένων και πάγωμα έκδοσης.
