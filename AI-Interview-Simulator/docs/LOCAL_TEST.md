# Τοπική δοκιμή χωρίς ερευνητική συλλογή

Το μήνυμα απενεργοποίησης είναι σκόπιμο: το κανονικό appsettings.json κρατά Study:CollectionEnabled=false και μη εγκεκριμένη συναίνεση. Μην αλλάξετε αυτά τα πεδία για screenshots ή προσωπικές δοκιμές.

## Εκκίνηση

Από τη ρίζα της λύσης, σε δύο τερματικά:

```sh
dotnet run --project AIInterviewSimulator.Api --launch-profile LocalTest
```

```sh
dotnet run --project AIInterviewSimulator.Client --launch-profile LocalTest
```

Ανοίξτε **http://127.0.0.1:15265/**. Το API ακούει μόνο στο http://127.0.0.1:15055/. Στο Rider επιλέξτε το προφίλ LocalTest χωριστά για API και Client. Απαιτείται το ήδη εγκατεστημένο SDK .NET 10.

## Χρήση

- Βεβαιωθείτε ότι βλέπετε ΤΟΠΙΚΗ ΔΟΚΙΜΗ. Χρησιμοποιήστε μόνο επινοημένα στοιχεία και απαντήσεις.
- Διαβάστε τη δοκιμαστική ενημέρωση και επιλέξτε το checkbox. Διατηρούνται οι έλεγχοι αποδοχής, έκδοσης, πρόσβασης και οι server μεταβάσεις.
- Μετά την έναρξη η προειδοποίηση δείχνει την πραγματική ανατεθειμένη συνθήκη Α ή Β. Η υφιστάμενη ισορροπημένη κατανομή παραμένει αμετάβλητη. Σε νέα άδεια δοκιμαστική βάση, δύο διαδοχικές συνεδρίες καλύπτουν και τις δύο συνθήκες· δεν υπάρχει χειροκίνητη επιλογή condition στο ερευνητικό API.
- Για νέα δοκιμαστική συνεδρία πατήστε Τερματισμός πρόσβασης και επιβεβαιώστε. Η προηγούμενη πρόσβαση ανακαλείται και επιστρέφετε στη φόρμα. Το refresh επαναφέρει την ίδια συνεδρία όσο ισχύει το cookie.
- Το Α χρησιμοποιεί τον πραγματικό rule-based μηχανισμό. Το Β χρησιμοποιεί το κανονικό prompt/pipeline με in-process HTTP stub: σταθερό δοκιμαστικό κείμενο, καμία εξωτερική κλήση και καμία χρέωση. Δεν ελέγχεται ποιότητα πραγματικού Gemini.
- Για screenshots HAX κρατήστε την ένδειξη δοκιμής και σημειώστε ότι οι εικόνες Β τεκμηριώνουν τη ροή, όχι πραγματικό AI feedback. Η προηγούμενη αναφορά HAX είναι στιγμιότυπο πριν από την προσθήκη του LocalTest και οι γραμμές πηγών μπορεί να έχουν μετακινηθεί.

## Διαχωρισμός και προστασίες

Η SQLite αποθηκεύεται αποκλειστικά στο AIInterviewSimulator.Api/.local-test/LOCAL_TEST_ONLY.db. Εκεί εφαρμόζονται αυτόματα οι migrations, μόνο στο ρητό LocalTest. Η κανονική interview_simulator.db δεν ανοίγεται ούτε μεταναστεύει από αυτή τη λειτουργία. Τα ερευνητικά δεδομένα δεν εισάγονται αυτόματα. Οι δοκιμαστικές εγγραφές κρατούν ConsentVersion=LOCAL-TEST-ONLY-v1.

Το client χρησιμοποιεί χωριστό cookie Interview.LocalTest και Data Protection εφαρμογή/κλειδιά στο Client/.local-test/keys. Οι φάκελοι .local-test αγνοούνται από το Git. Μην αντιγράφετε τη δοκιμαστική βάση στην ερευνητική και μην μοιράζεστε cookies/κλειδιά. Οι δοκιμαστικές εγγραφές παραμένουν μετά τη διακοπή.

Η σημαία LocalTesting:Enabled γίνεται true μόνο μέσω του επιλεγμένου profile. Η εφαρμογή αρνείται εκκίνηση με αυτή τη σημαία σε Production ή Staging, απορρίπτει custom Kestrel endpoints, δεσμεύεται στο loopback και απορρίπτει μη τοπικές συνδέσεις. Μην την τοποθετείτε πίσω από δημόσιο tunnel/proxy. Το κανονικό ερευνητικό gate δεν ενεργοποιείται μόνιμα: μόνο το απομονωμένο test process λαμβάνει στη μνήμη τη συνθετική ρύθμιση.

Δεν υπάρχει reset endpoint ή αλλαγή του production authentication. Σταματήστε τα δύο τερματικά με Ctrl+C όταν τελειώσετε. Τα συνήθη http/https profiles διατηρούν το μήνυμα απενεργοποίησης μέχρι να εγκριθεί η πραγματική συλλογή. Δεν έγιναν deployment ή πραγματικές κλήσεις Gemini.

## Έλεγχοι υλοποίησης

Build test project: μηδενικά errors/warnings. Πλήρες suite: 2.387 assertions, μαζί με ελέγχους Production/Staging rejection, loopback, χωριστής βάσης, συνθετικής συναίνεσης και προστατευμένου cookie. Πραγματικό Chrome με τα LocalTest profiles: δύο συνεδρίες που κατανεμήθηκαν σε Β και Α, συναίνεση, υποβολή, refresh, αναθεώρηση, δεύτερο feedback, συνέχεια στο στάδιο 2 και ανάκληση πρόσβασης. Δεν επανεκτελέστηκε επτάσταδο browser σενάριο στα νέα profiles· το πλήρες υφιστάμενο interview suite εκτελέστηκε χωριστά. Η πραγματική βάση ελέγχθηκε πριν και μετά και οι εγγραφές παρέμειναν αμετάβλητες. Δεν έγιναν πραγματικές κλήσεις Gemini.
